CarSelector — как запустить эту копию проекта
=============================================

Код скопирован БЕЗ виртуального окружения (папка .venv не переносится: внутри неё
прописаны абсолютные пути). Поэтому окружение нужно создать заново — один раз.

Откройте PowerShell в этой папке и выполните по очереди:

1) Создать окружение.
   Путь к Python указан полностью: обычный "python" на этой машине — заглушка
   Microsoft Store и завершается с ошибкой 9009.

   C:\Users\mutel\AppData\Local\Python\pythoncore-3.14-64\python.exe -m venv .venv

2) Установить зависимости (Flet, pandas, openpyxl, pytest):

   .venv\Scripts\python.exe -m pip install -r requirements.txt

3) Запустить приложение:

   .venv\Scripts\python.exe src\main.py

Дополнительно
-------------
Проверить приложение без открытия окна (9 проверок):

   $env:CARSELECTOR_HEADLESS=1; .venv\Scripts\python.exe scripts\smoke_check.py

Прогнать тесты (65 штук):

   .venv\Scripts\python.exe -m pytest tests -q

Пересоздать демо-набор data\cars.csv:

   .venv\Scripts\python.exe scripts\make_demo_data.py

Где что лежит
-------------
Оформление и цвета (вся палитра в одном файле) ... src\ui\theme.py
Паспорта ИИ-агентов .............................. .agent\*.agent.json

## 1. Цель и ценность

- Одна главная задача: пользователь загружает файл с автомобилями (марка, цена, пробег и др.)
  → задаёт параметры клиента (бюджет, пробег, год, марка, топливо, КПП, кузов, приоритет)
  → получает **отсортированный список лучших вариантов с оценкой 0–100 и объяснением**
  и дашборд со статистикой и диаграммами.
- Кто пользователь: менеджер подбора / клиент автосалона. Учебный проект для института.
- **Критерий приёмки (проверено):** запускаю `python src/main.py` → приложение открывается
  с демо-набором (91 автомобиль), задаю бюджет 2 000 000 ₽, пробег до 120 000 км, год от 2016
  → «Подобрать» → получаю 10 вариантов, отсортированных по итоговой оценке, с объяснениями
  от каждого агента; экран «Дашборд» показывает KPI и 5 диаграмм; экран «Агенты» показывает
  6 агентов, их скиллы, формулы и профили весов.
- Что НЕ входит в MVP: реальные API (Авто.ру/Drom), фото машин, авторизация, оплата,
  интернет-зависимые функции, мобильная сборка, README/пояснительная записка.

## 2. Стек (фактический)

- Python **3.13.7** в виртуальном окружении **`.venv/`** (на исходной машине было 3.14.6 —
  окружение переносить нельзя, оно создаётся заново из `requirements.txt`).
- GUI: **Flet 1.0.1** (десктопное окно) + **flet-desktop 1.0.1** (runtime окна).
- Диаграммы: **flet-charts 1.0.1** (PieChart, BarChart, ScatterChart, LineChart — нативные).
- Анализ данных: **pandas 3.0.6** + **openpyxl 3.1.5** (Excel).
- Тесты: **pytest 9.1.1**.
- Хранение: файлы (CSV/XLSX) + JSON-конфиги агентов. Базы данных нет.
- ИИ-агенты: **локальные экспертные модули** (правила + весовой скоринг), офлайн,
  без внешних API и ключей.

### Важно про окружение этой машины

## 6. Данные и модель

Ожидаемые колонки входного файла (распознаются автоматически по синонимам, регистру,
вхождению подстроки и похожести; латиница и кириллица равнозначны):

| Поле | Примеры названий в файле | Тип | Обязательное |
|---|---|---|---|
| brand | Марка, Make, Производитель | строка | да |
| model | Модель, Model | строка | нет |
| price | Цена, Цена, руб, Price, Стоимость | число | да |
| mileage | Пробег, Пробег, км, Mileage | число | да |
| year | Год, Год выпуска, Year | число | нет |
| fuel | Топливо, Тип топлива, Fuel | строка | нет |
| transmission | КПП, Коробка передач, Transmission | строка | нет |
| body | Кузов, Тип кузова, Body | строка | нет |
| engine_volume | Объём двигателя, Engine volume | число | нет |

Сущности:

- `Car { car_id, brand, brand_key, model, price, mileage, year, fuel, transmission, body,
  engine_volume, age, mileage_per_year }`
- `ClientRequest { budget_max, mileage_max, year_min, year_max, brands[], fuel, transmission,
  body, priority, top_n }`
- `AgentScore { agent_id, title, score 0..100, reasons[], weight }`
- `Recommendation { rank, car, total, scores[], reasons[] }`

Проверка данных (pandas): пустые строки, пропуски в цене/пробеге, дубликаты (марка+модель+
цена+пробег+год), выбросы (цена ≤ 0, пробег < 0), разбор «грязных» значений
(«1 350 000 ₽», «132 тыс. км», «2019 г.», «автомат» → «АКПП»).

## Агенты и скиллы (6 агентов)

| Агент | Тип | Что делает | Вес (сбалансированный профиль) |
|---|---|---|---|
| `fit` «Соответствие» | фильтр | жёсткий отбор по бюджету, пробегу, году, марке, топливу, КПП, кузову | — |
| `budget` «Бюджет» | оценка | запас бюджета; цена < 35 % бюджета ограничивается сверху | 0,30 |
| `mileage` «Пробег и износ» | оценка | запас до лимита (0,4) + пробег в год (0,6) | 0,30 |
| `reliability` «Надёжность» | оценка | экспертная шкала марки (55–95) − 8 баллов при возрасте > 15 лет | 0,25 |
| `market` «Рынок» | оценка | цена против медианы аналогов (модель → марка → вся база) | 0,15 |
| `expert` «Эксперт» | координатор | взвешивает оценки по приоритету клиента, формирует топ-N и объяснение | — |

Профили приоритета клиента (в `expert.agent.json`): `balanced`, `economy`, `low_mileage`,
`reliability`, `market`. Итог: `total = Σ(score × weight) / Σweights`, нормировано к 0–100.
