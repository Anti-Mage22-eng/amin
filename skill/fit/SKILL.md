# Скилл: Соответствие (fit)

**Агент:** `fit` — «Агент "Соответствие"»
**Тип:** фильтр (жёсткий отбор)
**Файл кода:** `.skill/fit/skill.py`
**Конфиг:** `.agent/fit.agent.json`

## Зачем нужен

Первый агент в цепочке. Пока он не пропустил автомобиль, остальные четыре агента
его даже не рассматривают. Это экономит вычисления и, главное, не даёт попасть в
рейтинг машинам, которые клиент не рассматривает по объективным причинам.

## Что проверяет

| Проверка | Условие отказа |
|---|---|
| Бюджет | цена > бюджета клиента |
| Пробег | пробег > лимита клиента |
| Год выпуска | год < «от» или год > «до», либо год не указан |
| Марка | марки нет в списке желаемых |
| Топливо | не совпадает с выбранным |
| КПП | не совпадает с выбранной |
| Кузов | не совпадает с выбранным |

## Интерфейс

```python
is_eligible(car: dict, ctx: dict) -> tuple[bool, str]
```

Возвращает `(True, "")`, если машина проходит, иначе `(False, "Цена выше бюджета")` —
текст причины показывается клиенту в отчёте об отклонённых вариантах.
