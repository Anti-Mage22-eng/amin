# Скилл: Надёжность (reliability)

**Агент:** `reliability` — «Агент "Надёжность"»
**Тип:** оценка 0–100
**Вес по умолчанию:** 0,25
**Файл кода:** `.skill/reliability/skill.py`

## Зачем нужен

Клиент покупает не только характеристики, но и будущие расходы на обслуживание.
Toyota и Land Rover одного года и цены — принципиально разные риски.

## Шкала (экспертная таблица, фрагмент)

| Оценка | Марки |
|---|---|
| 90–95 | Lexus, Toyota, Honda |
| 82–88 | Mazda, Subaru, Kia, Hyundai |
| 74–80 | Skoda, Nissan, Mitsubishi, Volkswagen, Haval, Renault |
| 68–73 | Geely, Chery, Lada, Ford, Peugeot |
| 60–66 | BMW, Audi, Jeep, UAZ, Land Rover |

Марка без оценки получает нейтральные **70** — агент не «выключается» на редких брендах.

## Формула

```
score = BRAND_SCORES[марка] или 70
если возраст > 15 лет → score − 8   # коррозия, износ, редкие запчасти
```

## Важно

Шкала учебная, составлена по сводной статистике отказов и отзывам сервисов.
Для реальной сделки её нужно заменять на актуальные данные (например, отчёт
надёжности ADAC или статистику обращений в сервис).

## Интерфейс

```python
evaluate(car: dict, ctx: dict) -> tuple[float, list[str]]
```
