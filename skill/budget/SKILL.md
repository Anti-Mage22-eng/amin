# Скилл: Бюджет (budget)

**Агент:** `budget` — «Агент "Бюджет"»
**Тип:** оценка 0–100
**Вес по умолчанию:** 0,30
**Файл кода:** `.skill/budget/skill.py`

## Зачем нужен

Отвечает на вопрос клиента «сколько денег останется после покупки». Две машины в
одном бюджете — 1 150 000 ₽ и 1 480 000 ₽ — не равноценны: у первой остаётся запас
на страховку, ТО и ремонт.

## Формула

```
ratio  = цена / бюджет
запас  = 1 − ratio
score  = 100 × min(1, запас / 0,45)

если ratio < 0,35 → score ≤ 82   # подозрительно дешёво: повод проверить машину
если ratio ≥ 1,00 → score = 0    # выходит за бюджет (обычно отсекает агент fit)
```

## Как читать оценку

- **100** — цена не выше 55 % бюджета, большой запас.
- **78** — цена около 65 % бюджета.
- **33** — цена около 85 % бюджета, запас минимальный.

## Пример обоснования

> Запас бюджета: 350 000 ₽ (23 % от бюджета)
